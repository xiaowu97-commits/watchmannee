倪柝聲紀念網頁

web.html
作品簡介

本專案為高質感一頁式歷史屬靈紀念網站，深入整理倪柝聲先生生平年表、核心著作選輯、心靈箴言與經典名句。介面提供即時全文搜尋高亮、字級無段縮放與佳句一鍵複製功能，讓讀者無論在行動裝置或電腦端，皆能享受典雅沉靜的閱讀與研究體驗。

使用到哪些 API
Clipboard API Web Storage API DOM Events API Google Fonts API
應用場景
  • 屬靈經典研討、歷史人物專題閱讀與文獻檢索
  • 每日心靈默想、佳句一鍵複製分享至社群平台
